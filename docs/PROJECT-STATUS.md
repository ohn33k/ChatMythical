# Project status

The mixed-version MythicalBackport line is paused at BETA v1.8.

Sunlit Compatible Skins v0.2 uses the native Cobblemon 1.5.2 model, poser, and animation system. It adds only compatible texture/layer variations and shader-only animated effects.

v0.2 restores the missing species-feature definitions and patches Pokémon-property suggestions so custom `mythical_*` keys are filtered by the species already typed. The filter is driven by the same generated compatibility table used by the grid and runtime appearance manager.

This is still an alpha build and requires in-game verification with the full modpack.
